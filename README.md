# ✈️ TravelWishly: Inteligencia de Viajes y Optimización Financiera

**TravelWishly** es una plataforma web avanzada diseñada para transformar la planificación de viajes internacionales en una experiencia fluida, segura y económicamente viable. El sistema actúa como una guía turística inteligente y un asesor financiero personalizado.

---

## 🚀 Misión y Visión

* **Misión:** Democratizar el acceso a la movilidad global mediante el desarrollo de una plataforma inteligente que simplifique la planificación de rutas complejas.
* **Visión (2030):** Consolidarnos como la infraestructura digital líder en inteligencia de viajes a nivel mundial, siendo reconocidos por nuestra capacidad de procesar datos y modelos predictivos.

---

## 🛠️ Stack Tecnológico

El proyecto utiliza un stack robusto enfocado en la escalabilidad y el análisis de datos:

| Componente | Tecnología | Descripción |
| :--- | :--- | :--- |
| **Backend** | **Python** | Procesamiento de lógica financiera y algoritmos de ahorro. |
| **Base de Datos** | **PostgreSQL** | Motor relacional robusto para persistencia de datos y seguridad. |
| **Frontend** | **HTML5 / CSS3** | Estructura semántica y diseño responsivo. |
| **Interactividad** | **JavaScript** | Manejo de mapas interactivos y gráficas dinámicas. |
